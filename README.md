# GlanceNav project page

Source of https://glancenav.github.io for the paper
**GlanceNav: Efficient Vision-and-Language Navigation with Streaming Memory and Counterfactual Rewind**.

Static site: `index.html` + `static/`. Robot videos are the original Unitree G1 recordings,
sped up 2× with light frame blending, 540×960 @ 60 fps H.264.
